# Vision Harmony

Create a premium, modern, highly aesthetic bilingual website for an Eye Clinic based in Bihar, India.

The website should feel trustworthy, medically professional, premium, clean, elegant, and modern — similar to a high-end private hospital or luxury healthcare brand.

Do NOT make it look like a generic hospital template.

PRIMARY GOAL

The main goal of the website is:

Build trust in the clinic and doctors

Clearly explain eye-care services

Introduce the clinic owner / lead doctor prominently

Introduce the medical and support team

Encourage visitors to contact the clinic

Make appointment booking extremely easy through WhatsApp or phone

Work perfectly for patients from Bihar

Support both Hindi and English

LANGUAGE

The website must support:

English | हिंदी

Place a clean language switcher in the header.

The Hindi version should use natural, professional Hindi suitable for patients.

Examples:

Book Appointment → अपॉइंटमेंट बुक करें
Our Services → हमारी सेवाएं
Meet Our Doctors → हमारे डॉक्टर
Contact Us → संपर्क करें
Call Now → अभी कॉल करें
WhatsApp Us → WhatsApp पर संपर्क करें

Do not use complicated Hindi medical terminology where simple language is better.
